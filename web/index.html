trit

A 15-million-parameter language model whose weights are all −1, 0 or +1. It was trained on short children's stories and runs here, in WebAssembly, from a 4.6 MB file.

The weights

Every linear layer inside the network is a grid of trits. Pick one to see it: each pixel is a single weight, −1, 0 or +1. The layer multiplies its input by this grid and then by one number, γ.

The model

Trained on TinyStoriesV2 (stories written by GPT-4, CDLA-Sharing-1.0); the weights carry the same licence. Code is MIT. Stories are made up by a very small model and can be odd.
